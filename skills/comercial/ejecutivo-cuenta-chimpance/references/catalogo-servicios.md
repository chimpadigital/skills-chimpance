Referencia interna con scopes y precios para armar propuestas. Los precios son base — Santiago puede ajustarlos según contexto comercial (descuentos, complejidad, urgencia, valor estratégico del cliente).

## 1. Web / Desarrollo

### 1.1 Web institucional con plantilla

**Modalidad**: trabajo sobre template preexistente, personalizado con branding del cliente.

**Etapas (5)**:
1. Kick Off — videollamada inicial + brief detallado
2. Presentación de 2 plantillas → cliente elige 1 (cliente tiene 5 días hábiles)
3. Diseño de prototipo en Figma (páginas, secciones, contenido, límites de caracteres)
4. Diseño UI — aplicación de identidad visual sobre plantilla
5. Programación del sitio web

**Plazo**: ~30 días hábiles desde primer pago + brief depurado.

**Limitación**: al ser plantilla preexistente, no incluye intervenciones artísticas personalizadas ni diseño a medida. Elementos personalizados (íconos, formas, ilustraciones) tienen costo adicional.

**Rango orientativo de precio**: ajustar según cantidad de páginas/secciones. Base sugerida desde USD 1.500 - 3.500.

### 1.2 Web institucional a medida

**Modalidad**: diseño UX/UI 100% personalizado.

**Etapas (4)**:
1. Kick Off
2. Diseño de prototipo Figma personalizado
3. Diseño UI a medida (identidad aplicada artísticamente)
4. Programación

**Tecnología típica**: React/Next.js para front.

**Caso de referencia**: Repowerlab. Web institucional + branding + marketplace = USD 13.700 total, en 6 cuotas de USD 2.283,33. Primera entrega web+branding al mes 3, marketplace 60-90 días adicionales.

**Rango orientativo**: USD 4.000 - 9.000 para web institucional a medida sola (sin branding, sin marketplace).

### 1.3 Marketplace / E-commerce avanzado

**Stack**:
- Front: React (componentes reutilizables, DOM virtual, alta interactividad)
- Back: Node.js (robusto y escalable)
- Base de datos optimizada
- Pasarela: Stripe
- Seguridad: encriptación + autenticación 2FA

**Funcionalidades clave**:
- Registro/login seguro para vendedores y compradores
- Publicación de productos con fotos, descripciones, precios
- Gestión de inventario
- Seguimiento de pedidos en tiempo real
- Integración con logística
- Cartera digital por usuario
- Sistema de comisiones por transacción (propuesta inicial 5-10%)
- Análisis de rendimiento

**Modelos de monetización a considerar**:
- Comisión por transacción
- Tarifa fija por venta
- % del precio de venta
- Promoción paga de productos
- Suscripciones premium con beneficios (menor comisión, más visibilidad)

**Plazo**: 60-90 días.

**Rango orientativo**: USD 6.000 - 15.000 según complejidad.

### 1.4 Web compleja con backoffice (sistema empresarial)

**Caso de referencia**: Provincia Microcréditos (web institucional + backoffice de gestión + constructor de landings + login + integraciones).

**Stack**:
- Backend: Laravel + API RESTful (robusto, seguro, Eloquent ORM, autenticación avanzada, protección CSRF, cifrado)
- Frontend: Next.js (SSR/SSG, rendimiento, SEO, internacionalización)
- Separación clara: Laravel API + Next.js consumiendo endpoints

**Funcionalidades del backoffice**:
- Gestión de contenido por usuarios no técnicos (textos, imágenes, botones, notas, formularios, secciones)
- Gestión de permisos y roles
- Sistema de autenticación propio
- Creación dinámica de formularios con campos de texto, fechas, selectores
- Validaciones avanzadas: DNI, email, integraciones con AFIP, RENAPER, NOSIS
- Envío automático de correos con datos de formularios
- Tracking de UTM para análisis de marketing
- API para GET/POST con paginación y filtros
- Acceso para equipo técnico del cliente

**Constructor de landing page** (módulo opcional):
- Editor drag-and-drop
- Componentes predefinidos + plantillas personalizables
- Gestión de texto, imágenes, formularios, multimedia
- SEO (metaetiquetas, descripciones, keywords)
- Previsualización y publicación

**Sistema de login** (módulo opcional):
- OAuth2 o JWT
- Perfil de usuario, gestión de info personal
- Estados de operación (ej. crédito, suscripción)

**Sitios embebidos**: iframes para integrar otros sitios.

**Accesibilidad**: alto contraste, control por voz, diseño inclusivo.

**Modalidad**: sprints de 2 semanas + reuniones semanales de seguimiento.

**Plazo**: ~7 meses para proyecto completo con backoffice + frontend + QA.

**Entregables típicos**:
1. Código fuente + acceso al repositorio
2. Historial de versiones
3. Código documentado
4. Documentación técnica (arquitectura, APIs, instalación, config)
5. Manuales de usuario
6. Prototipos UI/UX en Figma + User Flow + Wireframes
7. Sitio desplegado en producción
8. Garantía post-lanzamiento + soporte técnico inicial
9. Reportes QA + análisis de usabilidad
10. Backup, seguridad, logs

**Rango orientativo**: USD 25.000 - 60.000+ según alcance.

## 2. Marketing Digital

**Reglas generales**:
- Honorarios son MENSUALES, NO incluyen inversión publicitaria
- Cotización en dólar blue venta
- Inversión publicitaria mínima sugerida: USD 500 por cuenta
- Descuentos por contratación de más de 3 servicios (Santiago define %)
- Duración estándar de campañas: 6 meses
- Mes 1: armado (50% al inicio + 50% al fin del mes)
- Meses 2-5: ejecución (cobro días 1 al 5 de cada mes)
- Meta: tarjeta de crédito del cliente
- Google: transferencia, emite factura A

### 2.1 Social Ads (Meta - Facebook + Instagram)

**Precio**: USD 350/mes

**Objetivo**: derivar tráfico a landing page, anuncios específicos, segmentación a públicos determinados.

**Incluye**:
- Estrategia
- Campaña publicitaria de conversión
- Concepto publicitario
- Redacción y diseño de anuncios
- Optimización continua
- Informe mensual
- Asesoría y apoyo en proceso de venta

### 2.2 Red de Búsqueda (Google Ads - Search)

**Precio**: USD 350/mes

**Objetivo**: capturar visitas de usuarios con intención de compra. Crear presencia de marca en primeras posiciones.

**Incluye**:
- Estrategia para hasta 2 productos/servicios
- Análisis de palabras clave
- Campaña publicitaria de conversión
- Redacción de anuncios
- Optimización
- Informe mensual
- Asesoría y apoyo en venta
- Sugerencias de optimización web

### 2.3 Google Display

**Precio**: USD 380/mes

**Objetivo**: presencia y reconocimiento de marca mediante anuncios gráficos en YouTube, Red de Display, Búsqueda, Discover, Gmail, Google Maps.

**Incluye**:
- Estrategia
- Campaña publicitaria
- Planificación de medios
- Redacción y diseño de anuncios
- Concepto publicitario
- Optimización
- Informe mensual
- Asesoría y apoyo en venta
- Sugerencias de optimización web

### 2.4 LinkedIn Ads

**Precio**: USD 350/mes

**Ideal para**: B2B, captación de leads calificados, posicionamiento de marca profesional.

**Incluye**:
- Consultoría y estrategia inicial (análisis perfil actual, definición de objetivos)
- Segmentación avanzada (demográficos, ubicación, industria, cargo, intereses, comportamiento, remarketing)
- Gestión de campañas (configuración, lanzamiento, monitoreo, optimización en tiempo real)
- Análisis y reportes con métricas clave
- A/B Testing de anuncios y segmentaciones

### 2.5 Landing Page

**Precio**: USD 650 — pago único

**Incluye**:
- Estilo one page con 4 secciones
- Diseño UX
- Diseño UI
- Formulario de conversión
- Programación frontend
- Píxeles de terceros (Meta, Google Analytics, etc.)

**NO incluye**: hosting, dominio, producción de fotos.

**Landing adicional con misma estructura**: 20% del costo base.

### 2.6 Contenido integrado

**Precio**: USD 250/mes

**Objetivo**: crear 1 contenido principal y adaptarlo a Facebook, Instagram, LinkedIn y Blog.

**Incluye mensualmente**:
- 1 artículo principal de blog (largo, detallado, con contenido visual)
- 4 publicaciones en Facebook (resumen + enlace + imágenes/videos)
- 8 publicaciones en Instagram (4 stories + posts con infografías)
- 4 publicaciones en LinkedIn (artículo resumido en LinkedIn Pulse + gráficos)

**Servicios incluidos**:
- Creación de contenido principal
- Adaptación para cada red
- Distribución y publicación (calendarización)
- Monitoreo y optimización
- Informe mensual

**Beneficios**: consistencia de marca, eficiencia, mensajes coherentes.

### 2.7 Contenido dedicado por red social

**Precio**: USD 250/mes

**Objetivo**: contenido específico y personalizado para cada plataforma (no adaptado, sino diseñado para resonar con cada audiencia).

**Incluye mensualmente**:
- Facebook: 8 publicaciones (incluye 2 videos)
- Instagram: 12 publicaciones (incluye 8 stories)
- LinkedIn: 6 publicaciones (incluye 1 artículo largo en LinkedIn Pulse)
- Blog: 2 artículos largos

**Servicios incluidos**:
- Estrategia de contenidos (análisis audiencia + competencia + preferencias por plataforma)
- Calendario editorial específico
- Creación de contenido específico
- Distribución y publicación
- Monitoreo y optimización
- Informe mensual

**Aclaración**: Reels no incluidos en el costo base.

**Beneficios**: mayor engagement, optimización específica por plataforma.

### Metodología de trabajo Chimpancé para marketing

1. **Estrategia**: captación de leads, embudo de conversión, tácticas por fase del funnel, A/B testing, multivariantes
2. **Segmentación**: creación de públicos, grupos de palabras clave, públicos similares, bases de datos existentes
3. **Anuncios**: producción de variaciones (formato, redacción, titulares, imágenes, estilo)
4. **Landing Page**: variaciones por servicio
5. **Optimización**: medición cuantitativa y cualitativa, ajustes continuos

## 3. Branding

**Modalidad estándar**:
- 2 propuestas de logo → cliente elige 1
- Hasta 2 rondas de revisiones sobre la propuesta elegida

**Manual de identidad visual incluye**:
- Logo seleccionado
- Paleta de colores
- Tipografías
- Usos gráficos recomendados

**Branding completo (para proyectos integrales) incluye**:
- Investigación de mercado
- Análisis de audiencia objetivo
- Análisis de competencia
- Definición de mensaje y enfoque visual
- Conceptualización + creación de idea y concepto gráfico
- Diseño de isologotipo
- Elección de color
- Tipografía
- Estilo de ilustración/fotografía
- Composición visual
- Elementos visuales (formas, tramas, íconos)
- Optimización para web
- Creación de Brand Book
- Entrega de archivos finales en formatos y tamaños necesarios

**Propiedad intelectual**: el diseño final del logo y elementos de identidad son propiedad exclusiva del cliente luego del pago completo. El diseñador retiene derecho a mostrar el trabajo en portfolio.

**Rango orientativo**:
- Logo + manual básico: USD 800 - 1.500
- Branding completo (con investigación, sistema visual ampliado, Brand Book): USD 2.000 - 4.500
