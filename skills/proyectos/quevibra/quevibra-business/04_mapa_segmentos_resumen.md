# Mapa de segmentos — resumen operativo

> Versión resumida de los 163 subsegmentos consolidados. Sin fichas detalladas — solo nombres por estado de pre-lanzamiento.
>
> Para fichas con dolor, necesidad, valor agregado y monetización por subsegmento, ver skill complementario `quevibra-segmentos-detallado`.

## Cómo leer este mapa

Cada subsegmento tiene un **estado de pre-lanzamiento** que define si se ataca ahora, después, o si requiere experimento separado:

| Estado | Significa |
|---|---|
| **Foco inmediato** | Entra ahora en pre-lanzamiento. Prioridad alta. |
| **Foco con cuidado** | Entra ahora, pero con consideraciones de seguridad o comunicación (típico de adolescentes). |
| **Fuente de inventario** | No es cliente. Es proveedor de catálogo. NO le pedimos plata; le pedimos permiso para republicar, contacto, agenda pública. |
| **Amplificación** | No monetiza directo. Distribuye y multiplica. Periodistas, medios, curadores. |
| **Experimento separado** | Se atiende fuera del flujo principal, en paralelo, con propuesta dedicada. |
| **Validar después** | Entra en mes 2-3 según resultados iniciales del pre-lanzamiento. |
| **Futuro** | No es ciclo de pre-lanzamiento. Queda para después de PMF. |

## Cómo usar este mapa en tareas operativas

| Tarea | Mirá este mapa para… |
|---|---|
| Decidir a quién dirigís una campaña | Identificar si el segmento está en "Foco inmediato" o si conviene esperar |
| Escribir copy para un nicho | Confirmar si el subsegmento existe y en qué estado está |
| Pensar partnerships | Identificar "Fuente de inventario" para acuerdos sin plata |
| Comunicación con medios | "Amplificación" — periodistas y medios |
| Decidir si vender a empresas / sponsors | Si está en "Futuro", NO se le vende todavía |
| Planificar contenido de Instagram | Cruzar "Foco inmediato" con vocabulario propio del segmento |
| Preparar pitch a inversor o mentora | Mostrar el panorama completo (las 8 categorías) + el foco real del pre-lanzamiento |
