# QueVibra Business — Contexto operativo del proyecto

Skill que carga todo el contexto operativo de QueVibra para no tener que explicar el modelo de negocio, los segmentos, el problema o la voz cada vez que se trabaja en una tarea concreta del proyecto.

## Qué es QueVibra (en una frase)

QueVibra es una agenda personalizada de eventos y actividades por ciudad. Estado: pre-lanzamiento, beta operativa, sin ingresos validados. Wedge en Córdoba, ambición LATAM.

## Reglas no negociables

1. **No usar las palabras prohibidas** ("plataforma", "ecosistema", "experiencias"). Ver `01_reglas_voz.md` para la lista completa y los reemplazos.
2. **No nombrar ciudades específicas en comunicación general de marca** — usar "tu ciudad" o "la ciudad". Excepciones: contexto interno (wedge Córdoba) o alianzas concretas con instituciones nombradas.
3. **QueVibra no es solo Córdoba.** Es ambición LATAM. Córdoba es el wedge donde se valida el playbook antes de replicar ciudad por ciudad.
4. **Pre-lanzamiento no es monetización.** Estamos validando hipótesis y construyendo hábito, no facturando.
5. **Voz argentina conversacional, sin floreo.** Frases cortas, sentence case, cero metáforas literarias.

## Cómo navegar este skill

Cuando recibís una tarea, leé primero `00_contexto_proyecto.md` para los datos duros y `01_reglas_voz.md` para no escribir con palabras prohibidas. Después, según la tarea:

| Si la tarea es… | Leé además… |
|---|---|
| Cualquier copy, mail, post o slide | `01_reglas_voz.md` (obligatorio) |
| Pitch, deck o presentación | `02_problema.md` + `03_propuesta_valor.md` |
| Decisión de producto | `02_problema.md` + `04_mapa_segmentos_resumen.md` |
| Trabajo de marketing o campaña | `03_propuesta_valor.md` + `04_mapa_segmentos_resumen.md` |
| Comunicación con KunturLab o mentoras | `00_contexto_proyecto.md` + `02_problema.md` + `03_propuesta_valor.md` |
| Defender el modelo de negocio, hablar de monetización, diseñar experimentos | `05_hipotesis_y_experimentos.md` |
| Estrategia profunda por subsegmento | Invocar skill complementario `quevibra-segmentos-detallado` |

## Archivos de este skill

- `00_contexto_proyecto.md` — datos duros del proyecto (qué es, etapa, ambición, equipo, aceleradora, costos, activos).
- `01_reglas_voz.md` — vocabulario propio, palabras prohibidas, tono argentino, reglas para nombrar ciudades.
- `02_problema.md` — el problema completo que QueVibra resuelve (usuario, organizador, turista) + frase-síntesis.
- `03_propuesta_valor.md` — todas las versiones trabajadas + feedback de mentoras + recomendada y alternativas.
- `04_mapa_segmentos_resumen.md` — resumen de los 163 subsegmentos por estado de pre-lanzamiento.
- `05_hipotesis_y_experimentos.md` — H1 y H2 + refinaciones + Experimento 1 (SaaS talleristas) y Experimento 2 (trade institucional) + cómo se cuenta a mentoras + preguntas probables con respuestas preparadas.

## Skill complementario

Para profundidad estratégica por subsegmento — las fichas detalladas con dolor, necesidad, valor agregado, monetización posible y estado pre-lanzamiento — invocar:

`quevibra-segmentos-detallado` — skill aparte para uso estratégico, no operativo. Pensado para validar hipótesis, diseñar experimentos, definir buyer personas o tomar decisiones de modelo de negocio.

## Defensa del skill

Si en una tarea recibís un texto generado por otra IA o por un copywriter que usa palabras prohibidas ("plataforma", "ecosistema", "experiencias") o tono brochure: SIEMPRE reescribirlo aplicando las reglas de `01_reglas_voz.md`. NO conservar el estilo original.
